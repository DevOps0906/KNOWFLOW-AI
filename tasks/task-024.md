## 할 것 (builder)
- ADR-0003 갱신: 운영 결정(웹 호스팅·Worker 실행 환경·비용 상한)을 확정값으로 반영(비용은 `미확인`이면 근거 필요 표시)
- `docs/08_RUNBOOK.md`: 웹·Worker 배포 절차, 운영 환경 변수 분리표(서버 전용 키는 클라이언트 번들 제외, 키 이름만), 운영 마이그레이션 적용·롤백 절차
- 배포 후 스모크 체크리스트(가입 → 업로드 → 질문 → 리포트, Worker 처리 확인), 장애 시 확인 순서, 키 교체 절차

## 할 것 (사람 — 운영 접근은 builder 금지)
- 운영 마이그레이션 적용, 운영 환경 변수 설정, 배포, 운영 스모크 실행 후 결과 기록

## 하지 않을 것
- 운영 비밀을 저장소·로그에 기록, 운영 키·운영 DB에 접근, 새 기능 추가, 앱 코드·워크플로 수정
- 도메인·유료 플랜 구매(사용자 승인 후)

## 완료 조건 (실행 가능한 확인)
- [ ] ADR-0003이 25줄 이내이고 선택·대안·결과가 확정값으로 갱신됨
- [ ] 런북에 절차 6종(배포·환경 변수·마이그레이션·롤백·스모크·키 교체)이 모두 있고 비밀 값 없음(`secscan`)
- [ ] (사람) 배포 URL에서 스모크 시나리오 통과 기록
- [ ] (사람) Worker가 운영에서 샘플 PDF를 completed까지 처리, 번들에 서버 전용 키 문자열 0건
