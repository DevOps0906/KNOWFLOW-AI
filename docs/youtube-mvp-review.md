## 2. 안 A(Gemini URL 입력)의 약관 판단
| 단계 | 판단 |
|---|---|
| 수집 | 위험 낮음. 영상을 내려받지 않고 Google 공식 기능을 쓴다 |
| 전사 보유 | **미확인.** API 데이터가 아닐 가능성이 높아 30일 규칙 적용이 불명이다. 복제·2차적저작물 쟁점이 더 직접적이다. 전문이 청크에 기한 없이 남는다 |
| 서비스 재제공 | **미확인.** Google 입력 기능을 쓴다고 출력을 상용 재제공할 권리까지 생기는지는 별개다 |

전사 저장이 불가로 판정되면 전사 청크·임베딩을 파기하고 요약·시각 링크만 남긴다(요약 자체도 판정 대상). 이 경우 유튜브 자료의 질의응답은 빠지거나 질문마다 재분석이 필요하다.

## 3. 입력 경로 비교
| 안 | 내용 | 판단 |
|---|---|---|
| A | Gemini에 YouTube URL 전달 | 잠정 채택(2장 조건부) |
| B | 제3자 자막 API(Supadata 등) | 예비. 수집 방식의 약관 위험이 옮겨 갈 뿐 사라지지 않음 |
| C | 자체 yt-dlp + Whisper (YT2 방식) | 기각. 약관 저촉, IP 차단, 프록시 비용 |
| D | 크롬 확장으로 사용자 브라우저에서 자막 수집 (SecondB 방식) | 이후 검토. 배포물이 하나 늘어남 |
| E | YouTube captions API | 본인 채널 연동에서만 가능 |

URL을 직접 받는 대체 공급자는 현재 없다. Preview 종료나 차단 시 신규 유튜브 수집을 중단하고 안내하며, 기존 전사는 2장 판단을 따른다.

## 4. 중요 장면 캡처
| 등급 | 내용 | 실제 이미지 | 자동 | 위험 | MVP |
|---|---|---|---|---|---|
| L0 장면 카드 | 시각·제목·장면 설명. 클릭하면 공식 임베드 플레이어가 그 시각부터 재생. 썸네일은 YouTube 주소로 표시만(서버 프록시·`next/image` 금지) | 아니요 | 예 | 낮음 | 포함 |
| L1 사용자 캡처 | 사용자가 탭 공유를 승인하면 브라우저가 카드별 시각 화면을 캡처. 데스크톱 전용 | 예 | 반자동 | 미확인(III.E.1.a) | 법무 확인 후 포함 |
| L2 업로드 영상 캡처 | 권리를 확인한 업로드 파일에서 FFmpeg 키프레임 추출 | 예 | 예 | 중간 | 이후 권장 |
| X 서버 다운로드 캡처 | yt-dlp로 받아 프레임 추출 (YT2 방식) | 예 | 예 | 높음 | 기각(YouTube 서면 승인 시 재검토) |

- **한계:** 위험이 낮은 조합으로는 "유튜브 링크만으로 실제 캡처 이미지 자동 생성"이 되지 않는다.
- **L1 초기값(제안):** 비공개 프로젝트에만 저장, 영상당 20장, 공개 공유 금지, 시각·채널·링크 자동 표기, 권리자 요청·영상 삭제 시 제거.
- **L2를 미루는 이유:** 유튜브 캡처 문제를 풀지 못한다. 내려받은 YouTube 파일을 올리면 X가 사용자 손을 거쳐 재현되고, 영상 호스팅 책임(저작권법 제102·103조)은 미검토다. 업로드 영상의 전사 경로와 한도도 새로 필요하다.
- **L2 착수 시:** FFmpeg은 LGPL 빌드만, 장면 감지는 FFmpeg `select` 필터부터. 부족하면 PySceneDetect(BSD-3) 검토.

## 5. 처리 설계
`URL 검증 → videos.list → Gemini 분석(전사 구간·장면 후보만) → 시각 검증 → 청크·임베딩 → 별도 LLM 호출로 요약 → 인용 검증`

| 규칙 | 내용 |
|---|---|
| 동기 거절 | 웹 서버가 `video_id`를 뽑아 `videos.list`를 호출해 A-04에서 바로 거절: 비공개·미등록, 임베드 불가, 연령·지역 제한, 라이브, 어린이용(`madeForKids`), 길이 초과 |
| 요약 | Gemini 분석과 분리. 저장된 청크만 입력받아 실제 `chunk_id`로 인용 |
| 장면 카드 | 새 테이블 `source_moments`(RLS). `locator`로 겹치는 청크를 연결. 시각 설명은 "AI가 본 장면, 전사 근거 아님"으로 표시. 겹치는 청크가 없는 카드는 리포트 인용 불가 |
| 인용 의미 | 코드 검증은 청크 실재만 확인한다. 청크가 모델 출력이므로 말 자체의 정확성은 보증하지 못하며, 사용자가 해당 시각을 재생해 확인한다. 화면에 "AI 전사"로 표시 |
| 시각 검증 | 0 ≤ t < 영상 길이, 구간 순서·중복 확인. 위반 구간은 버리고 로그 |
| 분할 | 긴 영상은 구간(제안 20분)으로 나눠 호출. 잘린 출력은 실패 처리 |
| 재시도 | 비공개·정책 거절·입력 초과는 재시도 금지. 일시 오류만 재시도 |
| 비신뢰 입력 | 전사·제목·설명은 프롬프트 인젝션 방어 대상 |
| 중복 판정 | `(project_id, video_id)` 기준 |
| 한도(제안) | 영상당 2시간, 사용자 월 20시간, 서비스 전체 일 상한은 Phase 0 뒤 결정. 월 자료 처리 100건에 합산 |
| 재확인 | Worker 일일 스윕. 30일 지난 영상만 `videos.list`, 사용자 쿼터 미차감. 결과 없음·비공개 전환만 비활성. 쿼터 초과·장애는 판정 불가로 재시도 |
| 비활성 | `sources.unavailable_at`으로 표현, 검색·인용에서 즉시 제외. 소프트 삭제 유예를 합치지 않고 API 데이터는 30일 안에 파기. 리포트에 복제된 문장 처리는 법무 확인 항목 |
| 저작권 축소 | 긴 원문 인용 금지, 채널명·원본 링크 항상 표시, 권리자 삭제 요청 창구 |

## 6. Phase 0 검증 (구현 전)
권리 문제가 없는 영상(본인 채널 또는 재사용 허가 영상) 10편(제안), 한국어 포함.
1. 사람 전사 대비 **전사 충실도**, 무음·음악 구간의 허위 생성 여부.
2. 사람이 표시한 정답 시각과 ±10초(제안) 일치율. 긴 영상은 분할 비교.
3. 중요 장면 선정이 사람 판단과 겹치는 정도.
4. 토큰 사용량 × 정식 단가로 건당 비용 환산(Preview 무료라 실청구액은 판단에 쓸 수 없음). 2시간 영상의 컨텍스트·출력 상한 초과 여부.
5. 임베드 재생과 L1 탭 공유 캡처가 데스크톱에서 실제로 되는지.
6. YT2(MIT, 스타 0, 2026-03 이후 커밋 없음)는 품질 비교 기준으로만 쓴다. 코드 품질은 미검토.

통과 기준 수치는 1차 측정 후 정한다.
