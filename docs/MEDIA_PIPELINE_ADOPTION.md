# 미디어 파이프라인 적용 메모 (WhisperX)

작성일 2026-11-20. 상태: **제안**. 공용 기획 정본: `platform-docs:products/_platform-core/MEDIA_PIPELINE.md`. 코드·의존성은 바꾸지 않았다.

## 현황

| 항목 | 내용 | 근거 |
|---|---|---|
| STT 엔진 설계 | 기본 faster-whisper(MIT), CPU·엣지 whisper.cpp, 단어 시각·화자 구분은 WhisperX(BSD-2) + pyannote 선택 | `docs/blueprints/stt-voice/README.md:54` |
| 구현 상태 | STT 설계 문서 단계(실제 코드 미확인). 유튜브 기능은 플래그가 꺼져 있음 | `README.md` 진행 현황 |
| 영상 캡처 | 권리 확인한 업로드 영상에서 FFmpeg 키프레임 추출(L2, 이후 권장) | `docs/adr/0006-youtube-summary-and-capture-mvp.md` |

## 적용안

| ID | 내용 | 영향 | 선행 |
|---|---|---|---|
| K-1 | 전사 편집기의 "단어 시각" 선택안을 WhisperX로 구체화한다. 재생 위치 강조를 구간이 아닌 단어 단위로 할 수 있는지 평가 | 전사 편집기 | 스파이크 S1 |
| K-2 | 화자 구분은 pyannote 모델 약관 확인 전까지 범위에서 제외한다 | 범위 | S3 |
| K-3 | 공용 `SttResult`의 단어 필드 제안(공용 기획 5장)을 이 모듈 계약과 맞춘다 | 모듈 계약 | 공용 채택 |

## 검증 (개발 전)

| ID | 방법 | 합격 기준(제안) |
|---|---|---|
| S1 | 강의·회의 음성 3건(각 10분)에서 단어 시각 정확도와 처리 시간 비교 | 편집기에서 단어 단위 이동이 자연스러움 |
| S3 | pyannote 모델 약관(유료 서비스 사용 가능 여부) 원문 확인 | 확인 완료 전까지 화자 구분 제외 |
