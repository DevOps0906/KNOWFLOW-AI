# ADR-0007 설치형 앱(Android·Windows·macOS) — 원격 셸 방식
- 상태: 제안 (2026-11-12 사용자가 대상·방식·일정 결정, 아래 열린 결정은 미확정). 구현은 웹 배포(task-024) 뒤. 날짜: 2026-11-12
- 근거: `platform-docs/Capacitor.md` 1·2·4.2·4.3·4.4·4.9·4.10장, `Tauri.md` 1·2·5·9·11·13장(옮기지 않음)

| 항목 | 내용 |
|---|---|
| 맥락 | 사용자는 대시보드(S-06)에서 웹으로 쓸지 앱을 설치할지 고른다. 앱은 같은 사이트에서 내려받는다. 서버·DB·권한은 웹과 같고 새 기능은 없다. |
| 선택 | ① Android: Capacitor, APK 직접 배포 ② Windows·macOS: Tauri, 설치 파일 직접 배포 ③ 셸은 배포된 웹을 띄우는 **원격 셸**(정적 번들은 나중 재검토) ④ 스토어·iOS·PWA 범위 밖 |
| 대안 | 정적 번들 셸(가이드 기본안): 원격 코드 위험은 줄지만 Next.js 서버 기능·쿠키 인증 구조를 바꿔야 해 보류 |
| 결과 | 얻는 것: 웹 배포가 곧 앱 갱신, 인증·RLS·API 변경 없음. 잃는 것: 오프라인 불가, 웹 침해 = 앱 침해, 가이드 권고(Capacitor 2장 7번·Tauri 9장) 이탈. 스토어 심사가 없어 "웹 래퍼 반려"는 해당 없음(스토어 출시 시 재평가). 되돌리는 비용 낮음(셸만 교체) |

| 영역 | 결정 |
|---|---|
| 탐색 허용 | 운영 웹 origin 하나만(정확한 호스트, https만, 와일드카드·서브도메인 없음). Supabase·API 호출은 탐색이 아닌 fetch라 무관. OAuth·외부 링크·리다이렉트로 허용 밖에 가면 시스템 브라우저, 로그인 복귀는 딥링크. 앱 안 결제 화면 없음 |
| 원격 콘텐츠 위험 | 플러그인·IPC는 앱 수명주기·외부 링크 열기만(카메라·파일·푸시·로컬 DB·shell 금지). Tauri는 원격 origin에 IPC 명령 권한 0(capability remote 없음). CSP는 원격 웹이 자기 것을 가짐(웹 쪽 정본). `cleartext:false`, 운영 빌드 웹뷰 디버깅 끔 |
| 비밀·세션 | 셸에 service_role·AI 키·서명 키 없음(서명 키는 CI 시크릿). 쿠키 세션이 웹뷰에서 유지되는지 실기기 확인. 현재 로그인은 이메일·비밀번호뿐, 소셜 로그인이 생기면 시스템 브라우저+딥링크 |
| 오프라인 | 연결 없음 화면을 셸에 내장해 안내+다시 시도. 오프라인 기능 없음 |
| 지침 이탈 | 이탈: Capacitor 2장 7번·4.2(운영 `server.url` 금지), Tauri 9장(원격 URL 금지, CSP `script-src 'self'`). 이유: 사용자 결정, 웹 배포 후 빠른 제공. 대응: 위 탐색 허용·IPC 0·웹 CSP. 재검토: 스토어 출시 또는 오프라인 요구 시 정적 번들 ADR |
| 서명·업데이트 | Android 키스토어(분실=업데이트 불가, 백업) · Windows 코드 서명 · macOS Developer ID+공증. 화면·기능은 웹 배포로 갱신, 셸은 새 파일 수동 설치. 최소 셸 버전 안내는 제안 |
| 배포·무결성 | 설치 파일은 웹 정적 경로 밖에 두고 S-18에 버전·크기·SHA-256 표시(파이프라인이 해시 계산·목록 기록). 서명이 1차 보증, 해시는 전송 확인용 |

| # | 열린 결정 | 제안 | 상태 |
|---|---|---|---|
| 1 | 서명 인증서 종류·비용, Apple Developer 계정 | 비용·기간 미확인. 없으면 경고 안내 포함 비서명 베타 | 사용자 결정 |
| 2 | 설치 파일 저장 위치·접근(로그인만 / 공개) | task-024 호스팅 결정에 맞춤, 로그인 사용자만 | 미확정 |
| 3 | 셸 자동 업데이트 | 1차 수동(Tauri updater는 서명 키 관리 선결) | 미확정 |
| 4 | 쿠키 세션이 웹뷰에서 안 될 때 | Bearer는 웹 API 변경 → 별도 ADR | 실측 후 |
