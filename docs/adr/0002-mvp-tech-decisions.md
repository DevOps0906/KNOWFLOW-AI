# ADR-0002 MVP 기술·운영 결정 묶음

- 상태: 채택 (사용자 승인 2026-11-02, 린 검증 병행 조건부)
- 날짜: 2026-11-02

| 항목 | 내용 |
|---|---|
| 맥락 | PRD 7장 미결 7건과 05·02 미정 항목이 작업 분해를 막고 있었다. 사용자가 팀장 추천안으로 기획을 마무리하라고 결정했다. |
| 선택 | 아래 표의 값으로 확정한다. 측정이 필요한 값은 "잠정 + 확인 작업"으로 둔다. |
| 대안 | 별도 큐 서비스(운영 부담), 서버리스 Worker(큰 PDF 시간 제한), PGroonga(Supabase 지원 미확인), 하드 삭제(복구 불가). |
| 결과 | 작업 분해 가능. 잠정 값(임베딩·검색)은 골든셋 작업(task)에서 수치로 검증하고, 바뀌면 새 ADR로 대체한다. |

| 항목 | 결정 |
|---|---|
| 작업 큐 | Supabase 기반 큐(pgmq 우선, 불가 시 processing_jobs 테이블 폴링). 처리량은 착수 시 측정 |
| Worker 실행 환경 | 상시 컨테이너 1개(별도 서비스). 내부망·메타데이터 주소로 나가는 연결 차단, 서비스 키는 Worker 전용 환경 변수 |
| 임베딩 모델 | 잠정 bge-m3(1024차원). 골든셋 30~50문항 비교 후 확정. 라이선스 확인을 확정 조건에 포함 |
| 한국어 키워드 검색 | pg_trgm으로 시작, 골든셋 결과가 기준 미달이면 대안 검토 |
| 삭제 정책 | 소프트 삭제 → 30일 뒤 영구 삭제(벡터·청크 → Storage 원본 → 행 순서). 계정 삭제는 30일 안에 전부 파기 |
| 쿼터 초기화 | 월 단위, 요청 시 지연 계산(기간 시작일 비교). 예약 작업 없음 |
| 포인트컬러·테마 | 팔레트 A 청록(#0F5F66), 라이트 기본·다크 2차 |
| 태블릿 배치 | 2단(원문+채팅, 자료는 시트) |
| 리포트 템플릿·요약 깊이 | MVP 제외, 이후 |
| 키·쓰기 경로 | 브라우저=anon+사용자 JWT(SELECT만), 웹 서버=사용자 세션으로 쓰기 RPC, Worker=service_role(유일). authenticated는 INSERT·UPDATE·DELETE 회수, 쓰기는 SECURITY DEFINER RPC만([02#2](../02_ARCHITECTURE.md)) |
| 멱등·쿼터·큐 | `idempotency_keys` 테이블, `consume_quota` 원자 차감, `enqueue_job`(작업 행+pgmq 같은 트랜잭션), 만료 작업 회수([05](../05_DATA_MODEL.md)) |
| 요청 한도·격리 | 한도 상태 Postgres 저장, Worker 외부 연결 허용 목록, PDF 파싱 하위 프로세스 격리, usage_events 익명화 1년([PRD 8-1](../01_PRD.md)) |
| ADR 번호 예약 | 0003 호스팅·업로드 경로(task-002), 0004 임베딩·청킹(task-013) |
