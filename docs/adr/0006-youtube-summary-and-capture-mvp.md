# ADR-0006 유튜브 요약·중요 장면 캡처의 MVP 승격

- 상태: 채택 (2026-11-11 사용자가 권장안 전부 승인. 법무 확인은 미완료 게이트)
- 날짜: 2026-11-11
- 대체: [ADR-0001](0001-media-expansion.md) 선택 ①의 YouTube 부분만. 예약 값·`locator` 일반화는 유지
- 근거·상세: [youtube-mvp-review.md](../youtube-mvp-review.md)

| 항목 | 내용 |
|---|---|
| 맥락 | 사용자가 유튜브 영상 요약과 중요 장면 캡처를 최우선 과제로 정했다. 기존 PRD는 이를 확장 2단계로 미루고 전사 비용·약관 검토를 착수 조건으로 두었다. |
| 선택 | ① 공개 영상 URL을 Gemini에 직접 넘겨 전사 구간·장면 후보를 받고, 요약은 저장된 청크로 별도 생성해 시각 인용을 붙인다(잠정). ② 캡처는 시각·설명·임베드 재생을 묶은 장면 카드(L0)를 기본으로 하고, 사용자 승인 탭 캡처(L1)는 법무 확인 후 넣는다. ③ 서버에서 YouTube 영상·음성·자막을 내려받지 않는다. |
| 대안 | yt-dlp + Whisper + FFmpeg(YT2 방식): 자동 캡처가 되지만 약관 저촉·IP 차단으로 기각. 제3자 자막 API: 위험이 옮겨 갈 뿐이라 예비. 업로드 영상 키프레임(L2): 유튜브 캡처를 풀지 못하고 범위가 커서 이후. |
| 결과 | 얻는 것: 약관에 직접 걸리는 수집을 피하고 최우선 과제 착수. 잃는 것: 유튜브 링크만으로 실제 캡처 이미지 자동 생성 불가, 웹 URL 수집 지연, Gemini Preview 의존(URL 입력 대체 공급자 없음), 모델 전사라 인용 검증의 보증이 PDF보다 약함. 되돌리는 비용: 전사 저장 전에는 낮음, 전사 저장·재제공 불가 판정이 구현 뒤에 나오면 높음. |

## 결정
| # | 질문 | 결정 | 상태 |
|---|---|---|---|
| 1 | 이미지 없는 장면 카드(L0)를 MVP "캡처"로 수용하는가 | 수용. L1을 다음 순서로 | 결정 |
| 2 | 변호사 또는 YouTube API 지원팀 확인(전사 저장·재제공, 프레임 저장) | **유튜브 수집 작업 착수 전** 필수 | 결정, 확인 미완료 |
| 3 | Gemini 공급자 추가와 등급 | 유료 등급. 키는 서버 측만 | 결정 |
| 4 | 웹 URL 수집을 유튜브 뒤로 미룸 | 승인 | 결정 |
| 5 | Phase 0 결과가 나쁘면 유튜브 최우선을 철회하는가 | 전사 충실도 미달이면 철회 | 결정 |
