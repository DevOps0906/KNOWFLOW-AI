# 00 린 검증 — KNOWFLOW-AI

| 항목 | 내용 |
|---|---|
| 문제 | 한국어 자료(PDF·웹 페이지)를 모아 조사하는 사람이 여러 자료에서 근거를 찾고 정리하는 데 시간을 쓰며, AI 답변은 출처가 불분명해 다시 원문을 확인해야 한다. (문제의 크기·빈도는 `미확인`, 인터뷰로 확인) |
| 고객 | 1순위 가정: 한국어 자료 조사가 업무인 지식노동자(컨설턴트·기획자·대학원생). 세그먼트별 지불 의사는 `미확인` |
| 가설 | "한국어 자료 조사 지식노동자는 출처가 검증된 답변·리포트에 월 `미확인`원(가격은 인터뷰·사전예약에서 확인)을 낼 것이다" |
| 핵심 가치 | 출처가 검증된 답변·리포트 (요약 문장마다 저장된 청크 출처 연결, 근거 부족 시 명시) |
| 대안(경쟁) | ① 범용 AI 채팅에 파일 첨부 ② 영상·문서 요약 서비스(예: Lilys AI, 공개 화면 구조 대응은 [04-screen-map-and-layout.md#3](diagrams/04-screen-map-and-layout.md)) ③ 수작업(PDF 열람 + 노션·문서 정리). 경쟁사 가격·기능 수준은 `미확인` |
| 가장 싼 검증 | 랜딩+사전예약과 인터뷰 5명을 병행 |
| 통과 기준 | 임의 기준(근거 데이터 없음, 사용자 확정 필요). 인터뷰 3/5는 과반 공감을 최소 신호로 본 값. 2주 안에 ① 랜딩 방문자 200명 이상(가정: 지인·커뮤니티 유입) ② 사전예약 20건 이상(전환 10% 이상) ③ 인터뷰 5명 중 3명 이상이 "출처 확인 과정이 현재 가장 큰 불편"이라고 답하고 유료 사용 의사 표명 |
| 기한·비용 | 기한 2주. 비용: 랜딩 호스팅·도메인 등 외부 비용 `미확인`(무료 플랜 가정), 인력은 본인 |
| 수익 모델 | 구독(월 정액) 1순위 가정. 사용량(분석 자료 수·질의 수) 기반 한도 구분. 가격은 `미확인` |
| 자동화 가능성 | 랜딩 폼 → 사전예약 시트 적재 → 인터뷰 일정 안내 메일까지 자동화 가능. 인터뷰 진행·해석은 수작업 |
| 정부지원 연결 | AI·SaaS 창업 지원사업 후보 검토 가능. 구체 사업명·자격·시기는 `미확인`(공고 확인 필요) |
| 결과 | 검증 전 — 2026-11-02 사용자 결정으로 개발과 병행(조건부 진행). 랜딩 사전예약을 첫 작업(W0)으로 실행하고 결과를 여기에 기록한다. 미달이면 범위·가격을 재검토한다. 2026-11-11 유튜브 요약·중요 장면 캡처를 최우선으로 올렸다([ADR-0006](adr/0006-youtube-summary-and-capture-mvp.md)). 인터뷰에 "유튜브 영상 조사에서 시각 출처·장면 정리가 얼마나 불편한가"와 "이미지 없이 시각·설명·바로 재생이 묶인 장면 카드로 충분한가"를 추가하고 랜딩 문구도 맞춰 검증한다. Readray 등 이미 있는 요약 서비스와의 차별(시각 인용 검증)은 `미확인` |
