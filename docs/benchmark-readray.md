# 벤치마킹: Readray 시각 구조 (기준일 2026-11-02)

목적: 디자이너가 고해상도 시안을 만들 때 참고할 Readray(구 Lilys AI)의 **보이는 모습**만 정리한다. 기능 비교와 채택 여부는 [benchmark.md](benchmark.md)를 따른다.
근거: help.lilys.ai 도움말 본문과 그 스크린샷(앱 화면 캡처), readray.ai 공개 페이지. 로그인 뒤 화면은 도움말 스크린샷으로만 확인했다. 수치는 캡처 이미지에서 잰 **비율**이고 px 값은 캡처 배율을 몰라 쓰지 않았다. hex는 캡처 JPEG에서 뽑은 **근사값**이다(공식 토큰 아님).
스크린샷: 저작권 때문에 저장소에 복사하지 않았다(design/benchmark/ 없음). 아래 근거 URL의 도움말 글에서 직접 보면 된다.

## 공통 인상
- 따뜻한 미색 바탕(본문 약 #f9f9f1, 사이드바 약 #f6f3ea, 떠 있는 카드·패널 약 #fdfdf5) 위에 거의 검정(약 #1b1c14) 글자와 버튼. 강조색은 연두 계열 라임 하나뿐(진행 막대 약 #bbdf19, Pro 배지 바탕 약 #d5e994, 본문 형광 표시).
- 제목은 굵은 고대비 세리프, 본문·UI는 산세리프, 자료 메타 정보(채널·날짜·길이·URL·폴더 칩)는 고정폭 서체. 서체 이름은 미확인.
- 테두리는 1px 연한 베이지 선, 그림자는 떠 있는 패널에만. 버튼·칩·입력창은 알약형(완전 둥근 모서리), 카드는 중간 반경, 떠 있는 패널은 큰 반경.
- 아이콘은 가는 선 아웃라인(라이브러리 미확인), 채움 아이콘은 거의 없음.

## 디자인 지시 요약
1. 바탕은 따뜻한 미색 3단계(사이드바 < 본문 < 카드), 글자·주 버튼은 거의 검정, 강조색은 라임 하나만(진행·배지·형광 표시).
2. 제목은 세리프(자료 제목 최대, 소제목 중간), 본문·UI 산세리프, 메타 정보 고정폭. 3구간 폰트 토큰에 세리프 제목 크기를 따로 둔다.
3. 그림자는 떠 있는 패널(원문 뷰어·채팅·토글 선택 항목)에만, 나머지는 1px 연한 테두리.
4. 버튼·칩·입력창·필터는 알약형, 카드 중간 반경, 떠 있는 패널은 큰 반경.
5. 사이드바: 가져오기 → 자료(폴더 하위) → 대화 → 생성물, 하단에 크레딧·계정. 접으면 완전히 숨김.
6. 라이브러리: 가운데 좁은 단, 폴더 카드 줄 → 알약 드롭다운 필터 → 구분선 없는 썸네일 행(제목/회색 메타/오른쪽 날짜).
7. 리포트: 좌측 세그먼트 토글 + 번호 목차, 가운데 읽기 단, 자료 카드에 커버리지 배지, 근거 용어는 점선 밑줄 + 라임 형광.
8. 원문·채팅은 떠 있는 둥근 카드로 열고 고정하면 3단(약 3 : 4 : 2).
9. 채팅 입력은 하단 가운데 알약, 위에 행동 칩·안에 + / 모델 / 원형 보내기, 답 아래 테두리 알약 추천 질문.
10. 1200 이상 3단, 768~1199 리사이즈 없이 2단, 767 이하 하단 탭 + 채팅 하단 시트.
