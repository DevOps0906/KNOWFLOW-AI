## 1. 사전 고정(측정 전)

**상태: 사용자 승인 대기.** 아래 정의와 기준은 측정을 시작하기 전에 고정하며, 측정 결과를 본 뒤 바꾸지 않는다.

### 1.1 지표 정의
| 항목 | 정의 |
|---|---|
| 정규화 | NFKC, 공백·문장부호 제거, 영문 소문자. 라벨 `fillers: ignore`이면 단독 토큰 어·음·그 제외 |
| 숫자 | 아라비아 숫자와 한글 수사는 라벨 `numbers`의 인정 표기로 별도 평가하고 CER 계산에서 뺀다 |
| 전사 CER | 음절 CER = (치환+삭제+삽입) / 정답 음절 수. 세 항목을 분리 보고. 영문은 글자 단위. 영상별 값과 언어별 평균·최악 |
| 평가 창 | 라벨에 사전 고정. 20분 넘는 영상은 전체 라벨 금지(창 표본). 창 ±10초 안에 시작하는 전사 구간만 정답과 글자 정렬한다. 창 안에 시작한 전사 구간의 글자가 정렬에 쓰이지 않으면 삽입으로 센다(창 밖 ±10초 여유 구간의 남는 글자는 제외) |
| 빈 정답 문장 | 정규화(간투사 규칙 포함) 뒤 빈 문장은 CER·시각·기준선 분모에서 빼고 제외 건수를 보고. 평가할 문장이 하나도 없는 라벨은 오류 |
| 고유명사 | 라벨 `proper_nouns` 표기·별칭의 일치율을 별도 보고(CER에도 포함) |
| 시각 | 문장을 글자 정렬한 뒤 첫 일치 글자가 속한 전사 구간의 `t_start`와 정답 문장 시작의 차이가 10초 이하인 비율. 문장의 절반 이상이 일치하지 않으면 정렬 실패로 불일치 처리. 영상 위치 사분위별 평균·중앙 오차 |
| 무작위 기준선 | 예측 시각이 영상 길이 안에서 균등하다고 볼 때의 문장별 ±10초 일치 확률 평균(해석적 계산) |
| 유의성 | 일치 건수의 기준선 대비 z(정규 근사) ≥ 2.33, 단측 유의수준 약 0.01 |
| 비발화 구간 | 라벨 구간(무음·음악)과 겹치는 전사 구간을 센다. 구간 양끝 10초 띠와만 겹치면 "허용오차 안", 가운데와 겹치면 "허용오차 밖". 분당 값의 분모는 각각 띠와 가운데의 길이 |
| 비발화 예외 | `[음악]` 태그만 있는 구간은 허용. 노래 가사 구간의 출력은 허위가 아니라 `lyrics`로 분류하고 분모에서 제외 |
| 비발화 측정 불가 | 가운데 길이가 있는 무음·음악 구간이 0이면 "측정 불가"(0건 통과 금지). 번인 자막 유무로 층화 |
| 시각 검증 | 제품 설계와 동일: 0 ≤ t < 길이, 순서·중복 위반 구간을 버리고 건수 집계. 잘린 출력은 실패 처리 |
| 호출 | 온도 0. 첫 유효 응답 채택(좋은 결과 고르기 금지). 재시도는 429·5xx만 최대 3회, 재시도 토큰도 비용에 합산 |
| 채택·무결성 | 측정 모델·프롬프트 해시가 같은 실행 중 가장 앞선 유효 실행만 채택. 라벨이 없으면 호출 거부, 실행 기록의 라벨 해시가 현재 라벨과 다르면 `label_changed`로 측정 제외. append-only 원장과 응답 파일이 어긋나면 측정 거부 |
| 장면 겹침 | ±10초 안의 사람·모델 장면 대응 수. 참고값이며 판정에 쓰지 않는다 |
| 비용 | 영상의 모든 실행(실패·재시도·다른 조건 포함) 토큰 × 실행별 모델의 `pricing.json` 단가(출처·확인일 필수, 없으면 "단가 미확인"으로 토큰만 보고). 전체 합계도 같은 방식. 2시간 영상이 없으면 상한은 "미검증" |

### 1.2 제안 기준 (사용자 승인 대기)
**근거 데이터가 없는 임의 초기값이다.** 사용자가 승인해야 기준이 된다.

| 지표 | 제안 기준 |
|---|---|
| 한국어 음절 CER | 영상 평균 10% 이하, 최악 영상 20% 이하 |
| 숫자 일치 | 95% 이상 |
| 고유명사 일치 | 90% 이상 |
| 비발화 구간 허위(허용오차 밖) | 분당 0.2건 이하 |
| 시각 ±10초 일치 | 90% 이상, 무작위 기준선보다 유의하게 높음 |

판정 규칙: 전사 지표 미달이면 철회(ADR-0006 결정 5). 시각만 미달이면 사용자 재결정.
