# ADR — OCR 엔진 선택

- 상태: 채택 · 버전·라이선스·정확도 확인일 **2026-10-27** (2차 출처 다수 — 공식 페이지 재확인 전 수치는 사실로 쓰지 않는다)
- 맥락: 영수증·사업자등록증·계약서 이미지를 한국어로 읽어 필드를 뽑는다. 문서에 개인정보가 있어 **자체 호스팅**을 기본으로 하고, 파이프라인은 규칙 우선·사람 확정이다(`README.md` 2절).

## 선택
**PaddleOCR 3.x(Apache-2.0) 한국어 모델 자체 호스팅.** 보조 Tesseract(Apache-2.0), 상용 CLOVA OCR은 설정으로 선택.

## 대안
| 대안 | 장점 | 단점 | 판정 |
|---|---|---|---|
| PaddleOCR 3.x | 한국어 전용 모델(PP-OCRv5) · 문서 파싱 · CPU 가능 | GPU 시 속도 이점, 환경 의존성 큼(확인 필요) | **기본** |
| Tesseract 5 | 경량 · CPU · 단순 인쇄체 | 한국어 정확도 한계(확인 필요) | 보조 |
| 네이버 CLOVA OCR | 한국 문서 특화 · 영수증·명함 도메인 | 상용 종량제(가격 확인 필요) · **외부 전송** · 자체 호스팅 불가 | 선택(고지 필수) |
| Surya | 정확도 호평(자체 주장) · 레이아웃·표 | 코드 GPL · 가중치 수정 OpenRAIL-M(연매출·투자 $2M 초과 시 상용 라이선스) — 조건 확인 필요 | **제외** |

## 선택 기준 (수치는 출처 있는 것만)
| 후보 | 한국어 정확도 | GPU | 속도 | 호스팅 |
|---|---|---|---|---|
| PaddleOCR PP-OCRv5 Korean | 공식 문서 기재: mobile rec 88.0 · 다른 문서 평균 90.45 (데이터셋·지표 조건 **확인 필요**) | 선택 | 모바일 모델 빠름 | 가능 |
| Tesseract 5 | 확인 필요 | 불필요 | 빠름 | 가능 |
| CLOVA OCR | 확인 필요 | 불필요 | API | 불가 |
- 공개 수치가 없는 칸은 **자체 벤치마크 절차**로 채운다: 조직 실제 문서 샘플(영수증·사업자등록증·계약서 종류당 50장, 제안값)로 필드 단위 정확도 · 사람 수정 비율 · 페이지당 처리 시간 · GPU 유무별 비용을 같은 입력으로 측정.
- 출처: huggingface.co/PaddlePaddle/korean_PP-OCRv5_mobile_rec · paddlepaddle.github.io/PaddleX/3.1 text_recognition 문서.

## 결과
- 문서가 외부로 나가지 않아 개인정보 위탁·국외 이전 부담이 없다(CLOVA 선택 시에만 발생).
- 엔진을 바꿔도 `ocr_pages`·`ocr_fields` 구조가 같아 교체 비용이 낮다(엔진·모델·버전은 문서마다 기록).
- 정확도가 모자라면 사람 확인 화면이 보완한다. 자동 확정은 하지 않는다.
- 확인 필요(2026-10-27): PaddleOCR 최신 버전(참고값 3.4.0, 2026-01-29) · Tesseract 최신 버전(5.3.4까지 확인) · Surya 라이선스 조건 · CLOVA OCR 요금·약관 · 한국어 공개 수치의 평가 조건.
