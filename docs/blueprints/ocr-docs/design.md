## 2. 상태 배지 의미 색 (토큰 이름만, 색 + 텍스트/아이콘 함께)
| 값 | 토큰 | 비고 |
|---|---|---|
| 문서 queued / processing | --color-neutral / --color-info | 문구 "대기" / "처리 중", 단계 병기 |
| 문서 needs_review | --color-warning | 문구 "확인 필요", 낮은 신뢰도 필드 수 병기 |
| 문서 confirmed | --color-success | 문구 "확정", 이벤트 발행 표시 |
| 문서 rejected / failed | --color-neutral / --color-danger | 반려는 사유 병기, 실패는 "다시 인식" 안내 |
| 작업 queued / running | --color-neutral / --color-info | 진행률 병기 |
| 작업 succeeded / failed / cancelled | --color-success / --color-danger / --color-neutral | 취소는 텍스트로 구분 |
| 단계 preprocess·ocr·extract·validate·mask 진행 / 완료 / 실패 | --color-info / --color-success / --color-danger | 단계 이름 텍스트 병기 |
| 필드 신뢰도 기준 미만 | --color-warning | 아이콘 + "신뢰도 낮음 n%" |
| 필드 검증 실패 | --color-danger | 아이콘 + 실패 사유(체크섬·날짜·금액) |
| 문서 종류 active / disabled | --color-success / --color-neutral | |
| 전달 pending / delivered / failed / dead | --color-neutral / --color-success / --color-warning / --color-danger | |
- 각 배지 글자색은 짝 토큰 `--color-*-fg`, 대비 4.5:1(`design-preview --check`).

## 4. 대조·신뢰도·마스킹 표기
- **원본과 필드 나란히**: 데스크톱은 좌 원본 이미지 · 우 필드 표를 한 화면에 두고 스크롤을 독립시킨다. 모바일은 "원본 | 필드" 탭 전환이며 탭 전환 시 선택한 필드·페이지·확대 위치를 유지한다. 페이지 이동은 "n / N쪽" 텍스트 + 이전·다음 버튼.
- **좌표 하이라이트**: 필드 행을 선택·포커스하면 원본 위 해당 좌표에 테두리 박스(`--color-info`) + 필드 이름 라벨. 반대로 박스를 클릭하면 필드 행이 선택된다. 하이라이트는 색뿐 아니라 굵은 테두리와 라벨로 구분한다.
- **신뢰도 낮은 필드 강조**: 기준(설정값) 미만 행은 warning 배경 + 아이콘 + "신뢰도 낮음 n%" 텍스트, 목록 상단 요약("확인 필요 n개")에서 다음 필드로 이동 버튼. 검증 실패는 danger 텍스트로 사유를 값 옆에 병기.
- **수정 전 값**: 수정한 필드는 "수정 전 값"을 취소선 + 텍스트 라벨로 병기. 확정·반려된 문서는 필드 읽기 전용이며 "이미 확정됨" 안내.
- **마스킹 표시**: 주민등록번호 뒷자리 등 마스킹 값은 "123456-•••••••" 형태로 표시하고 "마스킹됨" 배지·스크린리더용 텍스트("뒷자리 마스킹됨")를 병기. 내보내기 화면에 "마스킹된 값만 포함" 문구를 항상 둔다. 원문은 화면·로그 어디에도 노출하지 않는다.
- 외부 전송(CLOVA OCR 선택 시)·국외 여부 고지는 문구 확정 전까지 자리만 두고 사람이 확정한다. 날짜는 KST 절대.

## 5. 접근성 체크
- [ ] 상태·신뢰도·검증 결과는 색 + 텍스트/아이콘, 좌표 박스는 테두리 굵기 + 라벨.
- [ ] 본문 대비 4.5:1, 입력창 경계 3:1, 포커스 링 토큰 항상 보임.
- [ ] 원본 이미지에는 대체 텍스트(문서 종류·페이지)를 두고, 필드 표가 같은 정보를 텍스트로 제공(이미지 없이도 수정 가능).
- [ ] 필드 행 선택은 키보드(↑↓·Enter)로 가능하고 하이라이트 변경을 `aria-live="polite"`로 알린다.
- [ ] 모바일 탭은 `role="tablist"`, 선택 상태 `aria-selected`, 탭 전환 시 포커스 위치 유지.
- [ ] 값 수정 오류(검증 실패)는 칸 옆 텍스트 + `aria-describedby`, 409 충돌은 새로고침 안내 Callout.
- [ ] 확정·반려·종류 사용 중지는 확인 단계 필수, 인식 진행은 `aria-busy` + 단계 텍스트.
- [ ] 터치 대상 최소 44px, 하단 고정 바가 본문·포커스를 가리지 않음, 375px에서 페이지 가로 스크롤 없음.
- [ ] `prefers-reduced-motion` 존중(진행·하이라이트 전환 애니메이션 제거).
