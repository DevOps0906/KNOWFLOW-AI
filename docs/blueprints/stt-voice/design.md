## 2. 상태 배지 의미 색 (토큰 이름만, 색 + 텍스트/아이콘 함께)
| 값 | 토큰 | 비고 |
|---|---|---|
| 작업 queued / running | --color-neutral / --color-info | 문구 "대기" / "처리 중", 조각 n/N 병기 |
| 작업 succeeded | --color-success | 문구 "완료" |
| 작업 failed | --color-danger | 사유 코드별 안내 병기, 재시도 소진은 텍스트로 구분 |
| 작업 cancelled | --color-neutral | 문구 "취소" |
| 단계 pending / running / succeeded / failed / skipped / cancelled | --color-neutral / --color-info / --color-success / --color-danger / --color-neutral / --color-neutral | 건너뜀·취소는 텍스트로 구분 |
| 녹음 queued / processing / done / failed | --color-neutral / --color-info / --color-success / --color-danger | 편집은 done 이후만 |
| 원본 보관 중 / 삭제됨 | --color-success / --color-neutral | 삭제됨은 "재생 불가·텍스트만 편집" 병기 |
| 요약 없음 / 생성 중 / 완료 | --color-neutral / --color-info / --color-success | 완료에도 "AI 생성" 표시 유지 |
| 구간 신뢰도 낮음 | --color-warning | 아이콘 + "확인 필요" 텍스트 |
| 전달 pending / delivered / failed / dead | --color-neutral / --color-success / --color-warning / --color-danger | |
- 각 배지 글자색은 짝 토큰 `--color-*-fg`, 대비 4.5:1(`design-preview --check`).

## 4. 녹음·동의·전사 편집 표기
- **녹음 중 표시**: 빨간 점만 쓰지 않고 "녹음 중" 텍스트 + 경과 시간(mm:ss) + 입력 레벨 막대(수치 병기) + 항상 보이는 "중지" 버튼(터치 대상 크게). 최대 길이 근접 시 warning 안내. 마이크 권한 거부는 danger Callout + 파일 업로드 대안.
- **동의 고지 화면**: 녹음 시작 전 고지 Callout(제3자 녹음 금지·통신비밀보호법, 문구는 확인 필요 항목으로 자리만) + 녹음 종류·녹음·처리 동의 체크. 미동의 시 "녹음 시작"·"받아쓰기 시작"은 `aria-disabled` + 사유 텍스트.
- **작업 진행률**: 진행 막대 + "조각 n/N"·"n%" 텍스트 + 단계 목록(정규화·조각 나누기·받아쓰기·병합·화자 구분·요약)의 단계별 배지. "화면을 나가도 서버가 계속 처리합니다" 안내 유지.
- **전사 편집기**: 재생 위치의 구간은 배경 강조 + 왼쪽 막대 + `aria-current`(색만으로 구분하지 않음). 화자는 색 + 이름/번호 라벨 + 아이콘 모양을 함께 쓰고 색 토큰은 화자 팔레트에서 순환. 타임스탬프는 버튼이며 클릭·Enter 시 그 시각으로 재생 이동. 신뢰도 낮은 구간은 밑줄 + "확인 필요" 배지.
- 편집은 텍스트·화자만, 시작·끝 시간은 읽기 전용으로 표시. 저장 전 변경은 "저장되지 않음" 텍스트, 충돌(409)은 새로고침 안내.
- 시간은 mm:ss(1시간 이상 h:mm:ss), 날짜는 KST 절대. 모든 AI 결과(전사·요약)에 "AI 생성 · 오류 가능" 문구 병기.

## 5. 접근성 체크
- [ ] 상태·화자·재생 위치는 색 + 텍스트/아이콘/모양(작업·녹음·구간·요약).
- [ ] 본문 대비 4.5:1, 입력창 경계 3:1, 포커스 링 토큰 항상 보임.
- [ ] 녹음 시작·중지·경과는 `aria-live="polite"`로 알리고, 중지 버튼은 키보드 단축 없이도 접근 가능.
- [ ] 진행률은 `role="progressbar"`(`aria-valuenow`) + 단계 변경은 `aria-live`.
- [ ] 편집기: 구간 목록은 키보드 이동, 타임스탬프 버튼 라벨은 "n분 n초로 이동", 재생 속도·재생/일시정지 버튼 라벨 제공.
- [ ] 동의 체크박스는 라벨 연결, 미동의 오류는 칸 옆 텍스트 + `aria-describedby`.
- [ ] 취소·원문 복원·보관 단축 같은 되돌리기 어려운 동작은 확인 단계 필수.
- [ ] 터치 대상 최소 44px, 하단 고정 바가 본문·포커스를 가리지 않음, 375px에서 페이지 가로 스크롤 없음.
- [ ] `prefers-reduced-motion` 존중(레벨 막대·진행 애니메이션은 정적 수치 대체).
