# ADR — 받아쓰기(STT) 엔진·모델 선택과 한국어 정확도 벤치마크

- 상태: 채택(기본 구성) · 버전·가격·정책 확인일 **2026-10**(2차 출처 다수 — 공식 릴리스·가격 페이지 재확인 전 수치는 사실로 쓰지 않는다)
- 맥락: 플랫폼 규칙 — 제3자 음성(회의·강의·상담)은 오픈소스 자체 호스팅만, 국외 이전 금지(그래서 외부 경로는 자기 신고가 아니라 기능 경로로만 판정)(study-note `01_PRD.md#6.2`). 음성 서버는 faster-whisper + silero-vad 구성, 5분 조각 기준(`_platform-core/VOICE_ARCHITECTURE.md#4`). 한국어 정확도의 **공개 수치는 확보하지 못했다**(미확인) — 그래서 아래 자체 벤치마크로 정한다.

## 결정 1. 엔진
**faster-whisper 기본(GPU 자체 호스팅), CPU·엣지는 whisper.cpp, 단어 타임스탬프·화자 구분은 WhisperX + pyannote(선택), 상용 API는 "마이크 직접 녹음 · 60초 이하 · 짧은 음성 입력 기능(음성 질문·음성 메모)"에만, 조직 설정 + 국외 이전 동의가 있을 때 허용.**
| 후보 | 장점 | GPU 요구·속도 | 한국어 정확도 | 단점 | 판정 |
|---|---|---|---|---|---|
| faster-whisper (MIT, 1.2.x · 2025-10 확인, 최신 미확인) | CTranslate2 기반 고속·저메모리, 자체 호스팅 | GPU 권장(CPU int8 가능), 원본 whisper 대비 빠름(공식 README 수치 확인 필요) | 같은 모델이면 원본과 비슷하다고 알려졌으나 정밀도·디코딩 옵션에 따라 달라질 수 있음 — **미확인, 벤치마크로 측정** | 서버 GPU 필요 | **기본** |
| whisper.cpp (MIT, 1.8.6 vs 1.9.1 출처 상충) | GPU 없이 CPU·엣지 실행 | GPU 불필요, CPU 기준 중간 | 양자화에 따라 하락 가능 — **미확인** | 대량 처리 느림 | **GPU가 없는 환경 대안** |
| WhisperX (BSD-2, 3.8.5 · 2026-04 단일 2차 출처) + pyannote (코드 MIT, 모델은 약관 동의 필요) | 단어 정렬 + 화자 구분 | GPU 권장, 추가 모델로 처리 시간 증가 | 화자 구분 정확도 미확인(한국어 포함) | 모델 약관·유료 서비스 사용 가능 여부 **확인 필요** | **선택 기능**(약관 확인 후) |
| 상용 API (OpenAI · CLOVA Speech 등) | 서버 GPU 불필요, 빠름 | 불필요 | **미확인** | 국외 이전·위탁 고지, 요금 미확인, 자체 호스팅 불가 | **기능 경로만** — 마이크 직접 + 60초 이하 + 음성 질문·메모, 설정 허용 + 국외 이전 동의 모두 충족 시 |
- 파일 업로드·회의·강의 녹음은 어떤 후보든 상용 API로 보내지 않는다(대체 경로도 없음, 실패 처리). 사용자의 "본인 발화" 자기 신고는 판정 근거로 쓰지 않는다.
- 라이선스(MIT·BSD-2·pyannote 약관)는 모두 **확인 필요** — 도입 전 원문 확인.

## 결정 2. 모델 large-v3 vs turbo 선택 기준
기준선 = `large-v3`(정확도 우선 가정). `turbo`는 아래 기준을 **모두** 통과하고 지연·VRAM 이점이 확인될 때만 기본으로 올린다. 조직 설정(STT-S08)에서 모델을 고를 수 있다. 모델 이름·제공 여부는 구현 시 공식 페이지로 확인한다.
| 기준 | 측정 | 판단 |
|---|---|---|
| 정확도 | 구성별 CER(벤치마크 4~5) | 기준선 대비 증가폭이 허용 이내 |
| 지연 | 5분 조각 p95 · RTF | 조각 p95 60초 이하 목표(study-note `01_PRD.md` 5절, 제안) |
| 자원 | GPU 메모리 · 동시 처리 수 | 목표 GPU에서 동시 작업 상한 확보 |
| 안정성 | 무음 구간 환각(없는 말 생성) 비율 | 기준선 이하 |
| 용어집 효과 | 용어집 켬/끔 CER 차이 | 효과 없는 구성은 용어집 안내 문구 조정 |

## 결과
- 자체 호스팅이라 외부 전송 위험은 낮지만 GPU 운영 부담이 생긴다(플랫폼 공용 음성 서버 재사용 가능).
- 한국어 정확도는 이 ADR의 벤치마크를 돌려 숫자를 채우기 전까지 **미확인**이다.
- 확인 필요(2026-10): 각 엔진 최신 stable 버전 · pyannote 모델 약관 · 상용 API 요금과 국외 이전 조건 · 한국어 공개 벤치마크.

## 한국어 정확도 자체 벤치마크 절차
목적: 엔진·모델·옵션 조합의 한국어 CER을 같은 조건으로 재서 기본 구성을 정한다. 아래 수치는 **제안값**(팀장 확정, ocr-docs와 같은 규모)이며 첫 측정 뒤 조정한다.

### 1. 샘플 구성 (권리·동의가 확보된 자료만)
| 구성 | 예 | 확인할 점 |
|---|---|---|
| 단일 화자 낭독·강의 | 직접 녹음 | 기준선 정확도 |
| 대화·회의(2인 이상) | 동의 받아 직접 녹음 | 겹침·말끊김, 화자 구분 |
| 전화 품질(저대역) | 변환한 샘플 | 대역 제한 영향 |
| 소음 환경 | 카페·이동 중 녹음 | 소음 내성 |
| 숫자·고유명사·영어 혼용 | 업무 용어 대본 | 용어집 효과 |
| 무음·잡음만 | 무발화 구간 | 환각 |
- 샘플 1개 = 30초~5분, 구성(종류)당 50개(제안값). 고객 실데이터는 쓰지 않는다. 공개 데이터셋을 쓰면 이용 약관을 **확인 필요**.

### 2. 정답 작성
사람 1명이 전사하고 다른 1명이 검수한다. 표기 규칙(숫자·띄어쓰기·구두점·추임새·영어 표기)을 문서로 고정하고 버전을 매긴다. 정답은 엔진 결과를 베끼지 않고 처음부터 작성한다.

### 3. 비교 구성 매트릭스
엔진(faster-whisper GPU · whisper.cpp CPU) × 모델(large-v3 · turbo) × 정밀도(기준 · 양자화) × VAD(켬·끔) × 용어집(켬·끔). 상용 API는 직접 녹음한 본인 발화 샘플에서만 선택 비교한다. 구성 간에는 입력·언어 설정·디코딩 옵션을 같게 둔다.

### 4. CER 측정
1) 엔진 결과와 정답을 같은 규칙으로 정규화한다(구두점·공백 제거 여부, 숫자 표기, 영문 대소문자를 규칙 버전으로 고정). 2) 문자 단위 편집거리(치환 + 삭제 + 삽입)를 계산한다. 3) CER = 편집거리 합 / 정답 문자 수 합. 4) 구성별 CER과 전체 CER을 따로 보고한다. 5) 어절 단위 WER은 보조로만 기록한다. 편집거리 도구는 구현 시 선택하고 라이선스를 확인한다.

### 5. 부가 지표
RTF(처리 시간 / 오디오 시간) · 5분 조각 p95 지연 · GPU 메모리 최대치 · 무음 구간 환각 비율 · 조각 경계 단어 오류 건수 · 같은 입력 반복 실행 결과 차이.

### 6. 통과 기준 (제안값)
| 항목 | 기준 |
|---|---|
| 기본 구성 선정 | 기준선(large-v3 · faster-whisper · GPU) 대비 CER 증가가 +2%p 이내인 구성 중 지연이 가장 좋은 것 |
| 구성별 하한 | 어떤 샘플 구성도 기준선 대비 CER 증가가 +2%p를 넘지 않음 |
| 지연 | 5분 조각 p95 60초 이하(제안 — study-note 기준) |
| 환각 | 무음 구간 환각 비율이 기준선 이하 |
| 재현성 | 같은 입력 3회 반복 측정의 중앙값을 결과로 쓴다 |
| 절대 CER 목표 | 첫 측정 후 팀장이 정한다. 공개 수치가 없어 지금은 정하지 않는다 |
통과하지 못하면 기본 모델을 바꾸지 않고(large-v3 유지) 원인(소음·용어·경계)별로 옵션을 조정해 다시 측정한다.

### 7. 기록 양식과 재측정 시점
| 구성 id | 엔진·버전 | 모델 | 정밀도 | VAD | 용어집 | 샘플 구성 | CER | RTF | p95 지연 | 환각 | 측정일 | 규칙 버전 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
재측정: 엔진·모델·CTranslate2 등 핵심 의존성 버전을 올릴 때, 정규화·표기 규칙을 바꿀 때, 기본 구성을 바꾸려 할 때. 결과 표는 이 ADR 또는 `docs/`의 측정 기록에 날짜와 함께 남기고 `README.md`의 "미확인"을 채운다.
