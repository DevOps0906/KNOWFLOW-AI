근거: `screens.md`, `_design-guide/DASHBOARD_PATTERNS.md` 2~3장(패턴 A~O). 색·크기 값은 프로젝트 `tokens.css`를 따른다(이 문서에 hex·px 없음). 와이어프레임은 `plan2spec`이 생성한다.

## 2. 셸·메뉴
- 공개 화면: 가운데 카드(좁은 폭), 위에 로고만. 다른 앱 링크·메뉴 없음. 카드 하단에 로그인↔가입 링크.
- 로그인 후: 조직 앱 셸. 계정 설정(S06)은 계정 메뉴에서, 멤버·역할(S09·S12)은 설정 메뉴 아래. 조직 전환(S08)은 헤더 조직 이름에서 연다.
- 멤버 초대·역할 변경 버튼은 admin 이상에게만 렌더(자물쇠 노출 금지). 직접 URL 접근은 서버 403.

## 4. 반응형 3구간
| 화면 유형 | ~767 | 768~1199 | 1200~ |
|---|---|---|---|
| 공개 카드(S01~S04) | 카드가 화면 폭을 채움(좌우 여백만), 소셜 버튼 세로 | 가운데 카드(좁은 폭) | 가운데 카드, 배경 여백 |
| 위저드(S05) | Stepper "n/4" 텍스트, QR 위·코드 아래 | 아이콘 Stepper | QR 왼쪽 · 코드 오른쪽 |
| 설정(S06·S07) | Tabs 가로 스크롤, 세션은 카드 목록 | 1열 폼 + 표 | 사이드바 + 본문 |
| 목록(S08·S09) | 카드 목록, 필터 시트 | 표, 보조 열 숨김 | 전체 열 표 |
| 상세·표(S11·S12) | 요약 → 탭 세로, 권한 표는 카드 안 가로 스크롤 | 2열 | 본문 + 요약 |
- 사이드바: ~1023 햄버거 시트, 1024~ 고정. 페이지 전체 가로 스크롤 금지.
| 토큰 | ~767 | 768~1199 | 1200~ |
|---|---|---|---|
| --text-display (미사용 · 공개 화면 환영 문구만) | 28px | 36px | 48px |
| --text-h1 (페이지·카드 제목) | 24px | 28px | 34px |
| --text-h2 (섹션 제목) | 20px | 22px | 26px |
| --text-body | 15px | 16px | 16px |

- 위 값은 시작점이며 최종 값은 `tokens.css`가 정답이다. 입력 칸 글자는 모바일에서도 본문 크기 이상(확대 방지). 코드·설정 키는 `--font-mono`.

## 5. 입력·표기 규칙
- 비밀번호: `type=password` + `autocomplete`(로그인 `current-password`, 가입·재설정 `new-password`), 표시/숨김 토글(이름 라벨 "비밀번호 표시"), 붙여넣기 허용. 규칙은 칸 아래에 미리 텍스트로 보여준다.
- 이메일 `autocomplete=email`, 이름 `name`, 생년월일 `bday`. MFA 코드: 숫자 6자리 `inputmode=numeric` + `autocomplete=one-time-code`, 자동 포커스·6자리 분할 칸 금지(단일 칸 권장).
- **가입 여부 비노출**: 로그인 실패(이메일·비밀번호 구분 없음), 재설정·가입 완료 안내는 항상 같은 문구. 오류 문구에 "없는 이메일"·"이미 가입" 표현 금지. 초대 없음·만료·사용됨도 같은 안내.
- 초대 이메일은 일부 가림(예: a***@도메인). 세션 위치는 IP 일부만.
- 날짜: KST, 절대 `2026-10-27`, 일시 `2026-10-27 14:30`. 초대 만료는 D-일수 병기.
- 되돌릴 수 없는 동작(계정 삭제 요청·조직에서 제거·모든 기기 로그아웃)은 위험 영역 + 확인 단계, 비밀번호 재확인은 S06.

## 6. 접근성 체크
- [ ] 상태는 색 + 텍스트/아이콘(활성·정지, 초대 상태, MFA).
- [ ] 본문 대비 4.5:1, 입력창 경계 3:1, 포커스 링 토큰 항상 보임.
- [ ] 폼: 라벨 연결, 오류는 칸 옆 텍스트 + `aria-describedby`, 필수는 "*"와 텍스트. 제출 실패 시 첫 오류 칸으로 포커스, 요약은 `role=alert`.
- [ ] 로그인 중·가입 중 버튼은 비활성 + 진행 텍스트(중복 제출 방지), 시도 초과(429)는 대기 시간을 텍스트로.
- [ ] 위저드 Stepper 현재 단계 `aria-current`, QR 옆에 설정 키 텍스트 대안 제공.
- [ ] 표: th scope, 행 동작 버튼에 대상 이름 라벨(예: "김OO 정지").
- [ ] 터치 대상 최소 44px, 375px에서 페이지 가로 스크롤 없음.
- [ ] `prefers-reduced-motion` 존중(토스트·시트 애니메이션 축소).
